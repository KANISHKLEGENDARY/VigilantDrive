# Explain and defend the measurements

## Ten-line project explanation

1. The detector produces bounding boxes for closed eyes, open eyes, and yawns.
2. Eye detections are converted into timestamped open/closed observations.
3. PERCLOS is closed-eye time divided by observed eye time over a rolling seconds-based window.
4. Yawns count rising edges after a debounce period, so a long yawn is not counted once per frame.
5. A transparent weighted score and explicit PERCLOS thresholds determine NORMAL, WARNING, and DROWSY states.
6. Hysteresis prevents the state from flickering when the score moves around a threshold.
7. The alarm beeps only in DROWSY and applies a cooldown between beeps.
8. I compare a plain YOLOv11s baseline against the same detector with FCBAM using the same held-out test split.
9. I report detector mAP and class precision/recall separately from temporal drowsiness-event recall.
10. I quote only values generated by the evaluation scripts and label the machine, split, and conditions used.

## Five candidate resume numbers

Do not fill these with estimates. Each must come from a completed run and be accompanied by the test conditions.

| Candidate measure | Why it is useful | Source command |
|---|---|---|
| Test mAP50 | Standard object-detection quality measure at IoU 0.50. | `python scripts/evaluate.py --weights runs/fcbam_yolo11s/weights/best.pt --data data/Driver_Drowsiness_YOLO.training_ready/data.yaml --split test` |
| Test mAP50-95 | Stricter localization measure across IoU thresholds. | Same evaluation command; use the JSON `mAP50_95` field. |
| Per-class precision and recall | Shows whether eye and yawn classes behave differently. | Same evaluation command; use each class entry in the JSON `per_class` object. |
| Drowsiness-event recall | Measures temporal-event detection against labeled clip intervals, not frame classification. | `python scripts/evaluate_demo.py --config config.yaml --clips data/sample_clips --labels data/sample_clips/ground_truth.json` |
| False alarms/hour on normal footage | Quantifies nuisance alerts during labeled normal clips. | Same demo command after using `normal: true` clips and verified interval labels. |

The demo evaluator is an initial implementation and needs validation on hand-labeled clips before its event numbers are resume-ready. It uses any temporal overlap to match an event; report that rule and manual-label protocol.
